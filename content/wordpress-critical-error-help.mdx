You open your website and see "There has been a critical error on this website." It usually means WordPress encountered an error it could not recover from. A plugin, theme or server software change can cause it, but the message alone does not tell us which.

Before changing several things at once, I would find out what stopped working and protect any recent business records.

## Check what still opens

Try your homepage, the page where you first saw the error, and your WordPress dashboard. Note whether the error affects every visitor or only people trying to do something specific.

For example, if the homepage opens normally but your checkout fails, I would focus on the checkout request and the tools it uses. If every page fails, the investigation is different.

Look in the inbox of the website administrator for a recovery email. WordPress has a [Recovery Mode](https://wordpress.org/documentation/article/recovery-mode/) that may let an administrator access the dashboard after certain fatal errors. If no email arrives, your hosting provider may still have useful error records.

## Do not lose today's orders to recover yesterday's website

A backup may be useful, but restoring an old database can replace information created since that backup. That could include orders, appointments and enquiries.

I would ask whether the website has taken any orders or received other important updates since the error began. Keep a current copy when possible and check the latest working backup before choosing a recovery method.

## Find the error before changing the site

I would review the recent changes and error logs, then isolate the failing component on a test copy when possible. WordPress's [debugging guidance](https://developer.wordpress.org/advanced-administration/debug/debug-wordpress/) recommends working with backups or a staging environment rather than exposing debugging information on a live site.

Once the error is addressed, check the actual customer journey, not just whether the homepage opens.

Send me the public address and the error message. You do not need to diagnose the plugin yourself before asking for help.
