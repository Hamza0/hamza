If Elementor is stuck on a loading screen, your public WordPress website may still be working normally. I would check the editor separately before assuming the entire website needs a repair.

You might be trying to change your opening hours, publish a new offer or update a page before an important event. Something that should take a few minutes can become a real interruption.

## Does every page have the same problem?

Try opening another existing page in Elementor. If only one page fails, it may contain a widget, custom code or content that triggers the problem. If every page fails, I would look at shared settings, plugin compatibility and the server.

Try a private browser window too. This can help distinguish a browser extension or stale browser data from a wider problem.

## Check the recent changes

Elementor and Elementor Pro need compatible versions. I would review which plugins, themes and WordPress components changed shortly before the editing problem began.

Elementor's [editor loading guide](https://elementor.com/help/elementor-not-loading/) describes using Safe Mode to isolate conflicts. If the editor opens in Safe Mode, that is useful evidence. It does not mean every other plugin should be disabled on a live business website.

Where possible, I would investigate a staging copy rather than interrupt your public website or online store.

## Do not assume your hosting needs an upgrade

A low resource limit can contribute to loading problems. But raising a memory limit will not fix an unrelated script error or an incompatible plugin.

I would look at the browser errors, the server logs and the request that fails before recommending changes to your hosting plan.

## What would help me understand your issue?

Tell me whether your customers can still open the website, whether one page or all pages are affected, and what changed recently.

You do not need to find the technical cause first. If the public site also displays a fatal error, my note on [WordPress critical errors](/blog/wordpress-critical-error-help) explains why that needs a different investigation.
