People should be able to read your website, move around it and use its controls. Small checks during development can prevent everyday frustrations.

## Use the right controls

A heading introduces a section. A link goes somewhere. A button does something, such as opening a menu or sending a form. Using the correct HTML element helps browsers and assistive tools recognise each purpose.

An icon needs a useful name too. A phone symbol can stay visually simple while its accessible label says “Call Hamza”. A tooltip alone should not carry that explanation.

Check destinations as well. If a project has no public page, show its description without an empty link that suggests otherwise.

## Put the mouse aside

Try moving through the page with the keyboard. Can you reach every button and link in a sensible order? Is it clear which control is selected? Can you close a menu or dialog and continue?

The visible outline around a selected control is called a focus indicator. It tells keyboard users where they are. Removing it can make a page difficult to operate even when every button technically works.

## Read it on a smaller screen

Check real titles and descriptions, including long ones. Text should wrap without hiding important information or covering nearby controls.

Review contrast in both light and dark themes. A pale caption that looks attractive on one background may be hard to read on another. Use words or symbols alongside colour when showing errors, choices or status.

Increasing text size is another useful check. The layout should leave room for the content people need.

## Keep movement optional

Animations should help someone follow a change without delaying reading or hiding information. Respect the device's reduced-motion preference and keep the feature usable without movement.

Automated checks can find some problems, including missing control names. Combine them with a manual check of the wording and interactions. Repeat the relevant checks when content or components change, because an edit can affect something that previously worked.
